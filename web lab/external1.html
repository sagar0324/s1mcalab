CSS Selectors

Element Selector:
An element selector selects HTML elements based on their tag name.
Example:p,h1,div.

ID Selector:
An ID selector is used to style one unique HTML element.
It is represented using the # symbol.

Class Selector:
A Class selector is used to style one or more HTML elements.
It is represented using the .symbol

Another Class Example:
The same class can be applied to multiple elements.
